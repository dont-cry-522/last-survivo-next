# 林地远征 · Last Survivor Next

俯视角生存射击游戏，使用 HTML5 Canvas 与原生 JavaScript。零运行依赖，支持电脑键盘和手机触屏。

## 战斗样稿 02

赤帽菇、灰爪兽和岩甲兽现在拥有独立的蓄力、出招与收招阶段：

| 怪物 | 蓄力预警 | 攻击 | 收招 |
| --- | --- | --- | --- |
| 赤帽菇 | 缩身 0.42 秒，锁定短距离路线 | 向前扑击 86 像素 | 停顿 0.72 秒 |
| 灰爪兽 | 伏身 0.65 秒，锁定直线 | 快速扑出 280 像素 | 停顿 0.90 秒 |
| 岩甲兽 | 举臂 0.90 秒，地面圆圈锁定落点 | 半径 70 像素砸地 | 停顿 1.15 秒 |

三种怪物在蓄力和收招时不造成接触伤害，每次出招最多命中一次。冻结/麻痹会暂停其攻击。扑击使用连续路径判定，避免低帧率时穿过玩家却漏判。

玩家恢复冲刺无敌和受击后的 0.5 秒保护时间，跑步起停采用渐变动作，冲刺增加俯身、围巾拉伸和速度线。普通命中、暴击与砸地使用不同的视觉反馈；新增蓄力、扑击与砸地音效。图鉴“攻击”模式展示完整阶段，时间参数与实战共用配置。

爆燃菇、岩冠督军及 Boss 的攻击方式暂时沿用上一版。怪物刷新时间、技能池与基础伤害未调整。这次调整会改变实战难度，仍需根据试玩反馈调节。

## 外观与动作样稿 01

原创 Canvas 角色：护目镜枪手、赤帽菇、灰爪兽、岩甲兽、爆燃菇、岩冠督军。

- 枪手保持直立，武器独立朝向目标；交替步伐、身体起伏、围巾摆动、射击后坐和受击反应。
- 怪物使用不同步态、轮廓、颜色与装备；死亡姿态短暂保留并淡出。
- 地面阴影和按世界纵坐标排列的角色遮挡；林地地表、暖色入口与控件。
- 图鉴可以切换行走、待机、攻击、受击、退场并暂停观察，与游戏共用绘制代码。
- 现有八类技能、伤害、碰撞半径、刷怪时间及自动攻击规则保留。Boss 仍沿用原来的美术与技能。

这是第一版方向样稿，采用程序绘制的二维角色，不是《奇幻射击》的原版素材，也不是最终精修美术。

## 操作

电脑：WASD 移动、Shift 冲刺、Esc 暂停、R 重开、M 静音；升级时点击或按数字选择。

手机：左侧摇杆移动、右侧冲刺，顶部按钮暂停、重开、静音和查看图鉴。推荐横屏。

## 本地运行

直接打开 index.html，或在目录运行 `python -m http.server 8080` 后访问 http://localhost:8080。

## 验证

`node --test tests/*.test.cjs`

回归检查覆盖：移动方向与武器瞄准分离、站立不产生尾焰、退场动画不受对象池复用影响、退场超时清理和重开清理。

战斗回归还覆盖：蓄力不伤人、方向/落点锁定、单次命中、死亡取消攻击、冻结暂停、对象池清理、连续路径判定、30/60/120 FPS 的冲刺距离、玩家无敌帧与反馈对象上限。

本次额外通过 Edge 自动浏览器检查：桌面移动、暂停、升级、重开；844×390、390×844、568×320 三种触屏尺寸的开始、冲刺与技能选择；图鉴五种动作。未在真实安卓手机上测试。

## 主要文件

- `classes/ForestArt.js`：角色、怪物、场景与开始画面的绘制。
- `classes/Player.js`：玩家移动、攻击与表现状态。
- `classes/Enemy.js`：怪物逻辑、退场快照与角色遮挡顺序。
- `gallery.html` / `gallery.js` / `gallery.css`：动态角色图鉴。
- `skills/`：原有八类技能。
