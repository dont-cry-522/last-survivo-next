# 林地远征 · Last Survivor Next

俯视角生存射击游戏，使用 HTML5 Canvas 与原生 JavaScript。零运行依赖，支持电脑键盘和手机触屏。

本仓库从原项目完整复制，保留原有 54 条历史提交。后续开发在这里进行。

## 武器样稿 04（当前版本）

命中音效更新：连发枪使用短促清脆的击中声，散弹枪使用低频撞击与碎屑声，火球使用爆燃与余响；各自暴击增加对应音色。普通怪与 Boss 共用此规则，不再叠加旧的通用命中声。同类命中声音限频，避免多颗散弹叠加过响。通过实际 Web Audio 离线渲染检查有效输出、同帧叠加限制和静音；听感仍需实际设备试玩。

开局选择连发枪、散弹枪或火球法杖。电脑可按 1 / 2 / 3 选择、Enter 出发，手机直接点选。场内“换武器 / 新一局”返回选择；确认出发会开始全新一局。R 与“重开”保留当前武器。

| 武器 | 基础射速 | 基础伤害 | 特点 |
| --- | --- | --- | --- |
| 连发枪 | 每秒 3 发 | 每发 12 | 射程 520，轻微追踪，短促枪声、弹壳与轻后坐 |
| 散弹枪 | 每秒 0.85 轮 | 每颗 8.4，五颗 | 射程 240，直线扇形散射，额外击退、双管枪身和重枪声 |
| 火球法杖 | 每秒 0.85 发 | 直击 27.6 | 射程 420，半径 65 的爆炸；其他目标受到直击伤害的 60%，普通怪附带 2 秒燃烧 |

火球同一弹体只引爆一次，不给主目标重复计算爆炸伤害；周围 Boss 可受到溅射，Boss 暂不附带燃烧。原有升级继续修改攻速、伤害、多发与穿透。数值为第一轮试玩基准，尚未完成长局平衡。高速弹丸使用连续路径判定，降低低帧率漏判。

新增测试覆盖武器弹数、散弹不追踪、武器选择数值重置、子弹复用、火球单次溅射与燃烧，以及高速弹丸碰撞。浏览器实测三种武器、换装和重开、升级、键盘移动及三个手机尺寸的选择与冲刺；未做安卓真机验证。

## 生灵样稿 03

玩家与五种怪物统一完善，仍使用原创二维 Canvas 美术，与图鉴共用绘制代码：

- 枪手：双手持枪、交替抬脚与落地、靴底细节、移动方向对应的身体倾斜；武器继续独立瞄准。
- 赤帽菇：菌盖随步伐轻晃，补菌褶、盖沿亮面和脚部动作，倒地时菌盖甩动。
- 灰爪兽：交替抬爪、摆尾、背毛和爪部细节，倒地时侧身伏低。
- 岩甲兽：膝腿承重、护甲裂纹与高光，倒地时下沉折膝。
- 爆燃菇：裂纹菌盖、发亮孢囊，靠近后原地膨胀、加速闪烁与火星；圆形预警 0.9 秒后引爆一次。可以离开范围、冻结暂停引信，或提前击倒它阻止爆炸。
- 岩冠督军：独立胸甲、裙甲和嵌玉重斧；举斧 0.8 秒锁定前方约 151°、半径 110 像素的扇形，横扫 0.28 秒，收斧 1.1 秒。背后安全，攻击最多命中一次，扇形边缘计算玩家碰撞半径。

受击偏移跟随来弹方向。爆炸与横扫增加对应视觉和音效。修复屏幕外的扑击怪预警可能被裁掉的问题。图鉴增加“移动射击”和“冲刺”（展示枪手动作，其他怪物继续行走）。

所有五种怪物均有明确预警；Boss 仍沿用原有表现。本轮未调整刷新时间、角色伤害与技能池，但自爆怪和精英怪的新行为会影响难度，需要继续试玩调节。

## 战斗样稿 02（历史更新）

赤帽菇、灰爪兽和岩甲兽现在拥有独立的蓄力、出招与收招阶段：

| 怪物 | 蓄力预警 | 攻击 | 收招 |
| --- | --- | --- | --- |
| 赤帽菇 | 缩身 0.42 秒，锁定短距离路线 | 向前扑击 86 像素 | 停顿 0.72 秒 |
| 灰爪兽 | 伏身 0.65 秒，锁定直线 | 快速扑出 280 像素 | 停顿 0.90 秒 |
| 岩甲兽 | 举臂 0.90 秒，地面圆圈锁定落点 | 半径 70 像素砸地 | 停顿 1.15 秒 |

三种怪物在蓄力和收招时不造成接触伤害，每次出招最多命中一次。冻结/麻痹会暂停其攻击。扑击使用连续路径判定，避免低帧率时穿过玩家却漏判。

玩家恢复冲刺无敌和受击后的 0.5 秒保护时间，跑步起停采用渐变动作，冲刺增加俯身、围巾拉伸和速度线。普通命中、暴击与砸地使用不同的视觉反馈；新增蓄力、扑击与砸地音效。图鉴“攻击”模式展示完整阶段，时间参数与实战共用配置。

该版尚未调整爆燃菇、岩冠督军及 Boss，前两者在样稿 03 中已更新。

## 外观与动作样稿 01

原创 Canvas 角色：护目镜枪手、赤帽菇、灰爪兽、岩甲兽、爆燃菇、岩冠督军。

- 枪手保持直立，武器独立朝向目标；交替步伐、身体起伏、围巾摆动、射击后坐和受击反应。
- 怪物使用不同步态、轮廓、颜色与装备；死亡姿态短暂保留并淡出。
- 地面阴影和按世界纵坐标排列的角色遮挡；林地地表、暖色入口与控件。
- 图鉴可以切换行走、待机、攻击、受击、退场并暂停观察，与游戏共用绘制代码。
- 现有八类技能、伤害、碰撞半径、刷怪时间及自动攻击规则保留。Boss 仍沿用原来的美术与技能。

这是第一版方向样稿，采用程序绘制的二维角色，不是《奇幻射击》的原版素材，也不是最终精修美术。

## 操作

电脑：WASD 移动、Shift 冲刺、Esc 暂停、R 重开、M 静音；升级时点击或按数字选择。

手机：左侧摇杆移动、右侧冲刺，顶部按钮暂停、重开、静音和查看图鉴。推荐横屏。

## 本地运行

直接打开 index.html，或在目录运行 `python -m http.server 8080` 后访问 http://localhost:8080。

样稿 03 新增自爆预警、击倒取消爆炸、冻结引信、精英扇形正背面与边界、屏幕外预警可见性测试。

- `classes/Enemy.js`：怪物逻辑、退场快照与角色遮挡顺序。
- `gallery.html` / `gallery.js` / `gallery.css`：动态角色图鉴。
- `skills/`：原有八类技能。
